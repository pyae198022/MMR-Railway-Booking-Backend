# Myanmar Railways Data Reference
Based on official Myanmar Railways (ort.railways.gov.mm)

## Main Railway Lines

### 1. Yangon-Mandalay Main Line
- **Distance**: Approx. 620 km
- **Major Stations**: Yangon → Bago → Pyay → Taungoo → Naypyitaw → Thazi → Mandalay
- **Travel Time**: 12-16 hours

### 2. Yangon-Mawlamyine Line  
- **Distance**: Approx. 300 km
- **Major Stations**: Yangon → Kyaikto → Thaton → Mawlamyine
- **Travel Time**: 6-8 hours

### 3. Mandalay-Myitkyina Line
- **Distance**: Approx. 750 km
- **Major Stations**: Mandalay → Kyaukse → Sagaing → Monywa → Kalay → Hkamti → Myitkyina
- **Travel Time**: 18-24 hours

### 4. Mandalay-Lashio Line
- **Distance**: Approx. 300 km
- **Major Stations**: Mandalay → Pyin Oo Lwin → Hsipaw → Lashio
- **Travel Time**: 8-12 hours

## Train Types and Classes

### Train Types
1. **Express** - Faster trains with fewer stops
2. **Special** - Additional services and amenities
3. **Local** - Stops at all stations
4. **Scenic** - For tourist routes with scenic views

### Seat Classes
1. **Upper Class** - Air-conditioned, comfortable seats
2. **Ordinary Class** - Standard seating
3. **Sleeper** - Overnight trains with sleeping berths

## Regulations
1. **Booking Window**: Up to 30 days in advance
2. **Cancellation**: Up to 24 hours before departure (50% refund)
3. **Children**: Under 5 years free, 5-12 years 50% fare
4. **Senior Citizens**: 20% discount for ages 60+
5. **Students**: 15% discount with valid ID
